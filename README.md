# Road_crossing
## A simple game about crossing the road
Road Crossing is a simple game where the player has to cross a lot of roads to reach the end of the level, which are harder to cross every level, in total there are 4 levels, one harder than the last. 
## Various menus
Road crossing has a lot of menus, the first that is seen is a simple login menu which reads "user" files and checks if the username and password are correct, if not then it will not access, to add a new user, simply make a new text file with the username in the first line, and the password in the second.
## Overall
The game presents a simple yet intuitive Interface and the gameplay, even if simple, is fun
